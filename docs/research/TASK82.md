## 핵심 발견

1. **`stack`**(값) / **`class`**(형태) — **steady-state multi-turn 부하에서 해석 모형 v1 + B2가 사전 예측으로 재사용률(MAE 0.014), 구성 비용 비(Σ 오차가 구성 효과의 26 %), 점유 분포(TVD 중앙 0.061)를 맞혔다.** 세 항목 모두 영 예측기 대비 skill이 있다. 형태가 `class`인 근거: 입력은 descriptor 상수(용량·FIFO 의미론·step·prefill 비용)와 workload 통계뿐이고, 기전(FIFO 생존의 birth–death 근사, 곱 형태 점유)은 특정 구현이 아니라 시퀀스 단위 slot·FIFO 축출 설계 범주에서 나온다. 수치(0.014 등)는 이 기판의 것이다.
2. **`stack`** — **해석 v1의 오차는 BASE(batch 8)에 몰린다**: N8 −0.043, N10 −0.065, N12 −0.080(과소). batch 16 구성은 \|오차\| ≤ 0.008. 시뮬레이터는 BASE에서도 ±0.002. 용량이 부하에 가까워질수록(동시 running이 M에 닿는 비중이 클수록) v1 근사가 생존을 과소평가한다.
3. **`stack`** — **N = 8에서 모형 예측 h로 blind 선정한 DP 격자는 BATCHONLY보다 유의하게 싸고(짝 비 BATCHONLY/DP 1.0041, CI [1.0008, 1.0096]), TUNED 대비는 해상도 아래였다**(0.9920, CI [0.9857, 1.0050], 10 replicate). 예측(해석 0.9958, sim 0.9890)은 둘 다 CI 안.
4. **`stack`** — **동시 도착이 드문 steady state에서 시뮬레이터의 비용 비 오차는 원고의 42 % 크기로 줄었고 부호가 음으로 기울었다**(양수 1/7). 원고 조건의 계통적 양의 오차(8/8)는 이 부하에서 재현되지 않았다.
5. **`class`** — **prefill 크기 P와 도착 시 running 수 K는 양의 상관을 가진다**(12/13 cell). 근거: 재사용 실패(큰 P)는 용량 경쟁이 심할 때(큰 K) 일어나므로, FIFO 용량 제한이 있는 기판이면 같은 방향이다. 그래서 간섭 W의 독립 곱 예측은 과소로 편향된다(이 기판 BASE N12 +10 %).
6. **`universal`** — **60 s 해상도에서는 steady state가 아니다**: 평가 구간 전·후반의 h TVD(0.25–0.48)가 replicate 간 TVD(0.10–0.24)보다 크다. 비교는 120 s 합산 구간에서만 성립하며, 짧은 창의 점유 분포를 정상 분포로 쓰지 않는다.

## 해석

- **§5.2 skill은 예측(경계 0.50)보다 훨씬 좋았다(0.26).** 사전 계산은 "sim이 맞다면"을 가정했는데, 실제 관측은 해석과 sim 사이, 해석 쪽에 가깝거나 해석보다 더 효과가 컸다(N=8·10의 5 cell 중 DP N8을 뺀 4 cell에서 m < sim 예측). 즉 구성 효과는 sim이 본 것보다 크다.
- **H-sim `SUPPORTED`의 강도는 제한적이다.** (a)는 7 cell 이항 검정이라 1/7도 p = 0.125로 통과한다 — 검정력이 낮다. 오히려 음의 쏠림(6/7)은 "steady state에서는 sim이 구성 효과를 약간 과소평가한다"는 새 방향을 시사한다(hypothesis). 원고 오차의 원인이 동시 도착 가정이라는 가설과 모순되지는 않지만, "오차가 한쪽으로 몰리지 않는다"는 강한 형태는 지지하지 않는다.
- **재사용 영 예측기는 약하다.** 개발 집합(원고 조건, 0.676)과 steady-state 부하(0.70–0.92)의 수준 차 때문에 영 MAE가 커서, §5.1 skill은 "부하 조건 변화"까지 보상받았다. cell 간 차이만 보면: BASE 대 batch 16 차이(N8 0.10, N10 0.16)를 해석은 0.15·0.22로 과대 예측, sim은 0.10·0.16으로 맞혔다.
- **N = 12(적용 범위 경계)에서 깨진 것**: (i) 해석의 BASE 재사용(−0.080)과 BASE h(TVD 0.142 — B2의 n ≤ M 가정이 대기열에서 깨짐, TTFT 0.286 s가 대기열 존재를 보여줌), (ii) batch 16 구성의 평균 running을 해석이 0.4–0.5 과소, (iii) 비용 비에서 **세 예측기 모두 구성 효과를 과소**(관측 0.84·0.83 대 예측 0.86–0.89, CI는 넓어 포함) — N ≤ 10과 달리 해석이 sim보다 멀다. 해석의 절대 A′는 BASE +5 %, TUNED +7 %로 커진다.
