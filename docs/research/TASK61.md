## 핵심 발견

1. **`universal`** — **탐색 harness의 인자 의미가 문서의 정의와 한 칸 어긋나 있었다.** `--max-buckets`는 이름과 달리 중간 bucket 수 상한 + 1로 동작해 기본값으로 4,393개를 연다. 문서의 2,077은 정의로도, `--max-buckets 5`로도 재현되지만 기본 실행으로는 재현되지 않는다. **기본 실행은 선정도 바꾼다** — 7-bucket 구성 `(1,4,5,6,8,10,16)`이 최솟값(평가 0.9050)이 되고 기록된 선정은 19위로 내려간다. **실행 명령이 보존되지 않으면 이런 어긋남은 후보 수 하나로 역추적할 수밖에 없다.** 방법론 문제이므로 substrate와 무관하다.
2. **`stack`** — **기록된 선정이 현재 HEAD 시뮬레이터로 재현된다.** 2,077개 중 `(1,4,6,8,10,16)`·batch 16이 탐색 ratio의 유일 최솟값이고, 그 평가 ratio 0.906644가 기록 0.9066과 넷째 자리까지 같다. 축별 귀속의 두 값(0.9279, 0.9929)도 같다. 값은 이 descriptor와 워크로드에 묶인다.
3. **`stack`** — **이 시뮬레이터 경로는 process와 hash seed에 대해 결정적이다.** 서로 다른 `PYTHONHASHSEED`의 두 process가 byte 동일한 전표를 냈다. plan seed가 `hashlib.sha256` 기반이고 Python `hash()`를 쓰지 않는 것과 일치한다. 기준 구성을 한 번만 시뮬레이션한 재실행(A)과 후보마다 다시 시뮬레이션하는 commit된 harness(C)도 2,077개 전부 bit 동일한 ratio를 냈다. **따라서 원 탐색이 같은 코드·입력으로 돌았다면 출력도 bit 단위로 같았을 것이다** — 원 출력이 없어 이 조건부 문장 이상은 말할 수 없다.
4. **`stack`** — **탐색 ratio 순위에서 1위와 2위의 차는 0.0014, 1위와 20위의 차는 0.0045이고 상위 20은 전부 batch 16이다.** batch 12의 최선은 352위(차 0.0140)다. 모형값이다.

## 해석

- **(해석)** 이 재실행이 세우는 것은 **"선등록 정의 + commit된 채점 코드 + 현재 HEAD로 기록된 선정과 평가 ratio가 다시 나온다"**까지다. **8월 23일의 원 실행이 이 인자와 이 코드로 돌았다는 것은 세우지 못한다** — 원 출력이 없으므로 대조 대상은 문서의 기록값(선정 구성, 넷째 자리 ratio 3개, 후보 수)뿐이다.
- **(해석)** 순위는 시뮬레이터가 매긴 것이며 compile하지 않은 후보의 device time은 모형값이다(논문 §6 마지막 문단이 이미 이렇게 한정한다).
- **(사실 대조, 판단 아님)** 논문 `paper/draft/04_simulator.md` 44행은 "the top candidates differ by percentage points of device time while the residual is one to two hundredths of a ratio"라고 쓴다. 이번 전표에서 **상위 20 후보 간 탐색 ratio 차는 0.0014–0.0045**이고, batch별 최선 간 차(16 대 12)는 **0.0140**(평가 0.0123)이다. 두 수치를 문장과 나란히 둔다. 문장 수정 여부는 판단 사항이다.

- **기록값 분해능 미만의 차이** (`UNKNOWN`). 0.9066·0.9279·0.9929는 넷째 자리까지라 ±0.00005 안은 판별 불가다.
- **선정 구성의 N별 평가 ratio와 탐색 ratio 원값** (`UNKNOWN`). 원 문서에 없다.
- **논문 6장의 공백 공시 문장 위치** (`PARTIAL`). 지시문은 6장이 이 공백을 공시한다고 했으나, `paper/draft/06_prescription.md`와 `paper/latex/sections/06_prescription.tex`에서 "탐색 명령·후보별 결과가 보존되지 않았다"에 해당하는 문장을 grep으로 찾지 못했다. 가장 가까운 것은 §6 마지막 문단의 "only the chosen configuration was built and measured … not established for candidates never compiled"다. 논문은 수정하지 않았다.
