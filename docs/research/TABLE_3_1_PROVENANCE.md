## 행 집합 — 지시문과의 차이 1건

지시문은 행을 "[TASK26](TASK26.md) 관측 4의 11개 조합 전부"라고 정하면서 괄호 안에
"[TASK19](TASK19.md) N∈{8,16} / [TASK20](TASK20.md) N∈{4,6,8,10,12,16} /
[TASK23](TASK23.md) 격자 개입"이라 부연했다. **두 서술이 일치하지 않는다.**

- 괄호 안 목록은 2 + 6 + 2 = **10개**이고 11개가 아니다
- [TASK26](TASK26.md) 관측 4의 실제 11칸은 격자 (1,2,4,8) N ∈ {3,4,5,6,7,8,10,12,16}
  **9칸** + 격자 (1,2,4,6,8) N ∈ {6,8} **2칸**이다
- 그 11칸에 **N=3·5·7이 포함**되고 **[TASK19](TASK19.md)의 두 셀은 포함되지 않는다**
  ([TASK19](TASK19.md)의 run은 [TASK26](TASK26.md) 관측 4의 합산 대상이 아니다)

표의 논지가 "**같은 조합**에서 두 지표가 반전한다"이고 device time 열이 그 11칸에만
존재하므로, **11칸을 그대로 행으로 삼았다.** 괄호 안 목록은 채택하지 않았다.

## padding 열의 합산 단위 — 7행은 대조 가능, 4행은 아니다

[TASK52](TASK52.md) §1은 padding을 **출처 run별로** 17셀에 나눠 인쇄했고,
[TASK26](TASK26.md) 관측 4는 device time을 **run을 가로질러 합산한** 11칸으로
인쇄했다. 두 분할이 같지 않다.

- **7행**(격자 (1,2,4,8) N ∈ {5,6,10,12,16}, 격자 (1,2,4,6,8) N ∈ {6,8})은 블록
  구성이 [TASK52](TASK52.md)의 한 셀과 **정확히 일치**한다 → 값을 직접 대조했다
- **4행**(격자 (1,2,4,8) N ∈ {3,4,7,8})은 두 run을 합산하므로
  [TASK52](TASK52.md)가 **나눠 인쇄한 값과 직접 대조할 수 없다.** 아래에 구성 값을
  전부 적어 둔다

| 격자 | N | 표의 p_gap / p_무gap | [TASK52](TASK52.md)가 나눠 인쇄한 구성 값 |
|---|---|---|---|
| (1,2,4,8) | 3 | 0.1178 / 0.1975 | 관측 격자 b0–b2 `0.0976 / 0.1660` + 표본외 b3–b5 `0.1328 / 0.2203` |
| (1,2,4,8) | 4 | 0.0347 / 0.0612 | sweep b0–b2 `0.0275 / 0.0662` + 표본외 b3–b5 `0.0410 / 0.0567` |
| (1,2,4,8) | 7 | 0.1578 / 0.1802 | 관측 격자 b0–b2 `0.1528 / 0.1710` + 표본외 b3–b5 `0.1626 / 0.1887` |
| (1,2,4,8) | 8 | 0.1626 / 0.0902 | sweep b0–b4 `0.1593 / 0.0914` + 관측 격자 b5–b7 `0.1675 / 0.0884` |

이 4행의 값은 **새로운 계산 방법이 아니라 같은 script·같은 셀 정의를 device time 열과
동일한 블록 목록에 적용한 결과**다. 두 열이 같은 합산 단위를 쓰지 않으면 "같은
조합"이라는 표의 전제가 성립하지 않는다.

## 표시 규칙 적용 결과

- **굵게 = 반전 행** (Δp > 0 이면서 device time 비 > 1): **5행** — 격자 (1,2,4,8)
  N ∈ {3, 4, 5, 6, 7}
- device time 비 > 1인 행: **11/11**
- † 격자 (1,2,4,6,8) 2행. 각주 "bucket 6의 step 비용은 4와 8의 보간값임"

## 확인되지 않은 사항

- `p`는 step 가중이지 시간 가중이 아니다([TASK52](TASK52.md)와 동일한 주의)
- 격자 (1,2,4,6,8) 두 행의 device time은 보간된 bucket 6 비용을 쓰므로 모형이 두
  겹이다 — 표의 † 각주가 그 사실만 담는다
- 격자 두 묶음은 **plan seed가 다른 run**이며, 표는 두 묶음을 나란히 놓을 뿐 격자
  간 차이를 인과로 제시하지 않는다
- LaTeX 판은 한국어 캡션·머리글을 담고 있어 **CJK 지원이 없는 현재 `main.tex`
  preamble로는 컴파일되지 않는다.** 영문화 시 캡션과 머리글만 교체하면 된다.
  파일 첫 두 줄에 주석으로 적어 두었다
