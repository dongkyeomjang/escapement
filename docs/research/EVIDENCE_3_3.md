# 3.3 주장별 근거표

각 주장을 **다섯 분류** 중 하나로 표시한다. 감사 기록은 [TASK59](TASK59.md),
계획은 [OBSERVATION_AUDIT_PLAN.md](OBSERVATION_AUDIT_PLAN.md)(commit `bd9b5ec`).

| 분류 | 뜻 |
|---|---|
| **소스 사실** | 설치 package 또는 저장소 코드에서 직접 읽은 것 |
| **직접 관측** | 그 run의 원자료가 그 양을 직접 담고 있는 것 |
| **재집계** | 저장 원자료에서 이번에 다시 계산한 것 |
| **모형 추정** | 비용 모형이나 근사를 거친 것 |
| **미확인** | 자료가 없어 닫히지 않은 것 |

## 세 실험의 분리

**3.3은 서로 다른 세 run을 연결한다. 단일 사건 추적이 아니다.**

| 실험 | 조건 | 무엇을 관측하는가 |
|---|---|---|
| A. 재사용 절벽 | 동시성 1 순차, 배경 m건 | 재사용 성립 여부, 재계산 token |
| B. prefill 주입 | bystander 4 streaming + 주입 1회 | 병행 세션의 도착 간격 |
| C. 용량 개입 | 동시 세션 8, non-streaming | 재사용 수, 계산량 |

**B만이 병행 세션 지연을 직접 관측한다. A와 C는 관측하지 않는다.**
