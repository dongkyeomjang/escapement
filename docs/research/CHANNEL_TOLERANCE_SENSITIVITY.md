# 채널 일치 허용차의 민감도 — 계산 결과

이 문서는 **사후 민감도 확인이며 판정의 재산출이 아니다.** [TASK34](TASK34.md),
[TASK35](TASK35.md), [TASK36](TASK36.md), [TASK40](TASK40.md)에 기록된 채널 판정은
그대로 유지되며 이 문서의 어떤 수치도 그 판정을 바꾸지 않는다. 아래는 수치와
목록만 담고 평가 문장을 담지 않는다.

산출: [`experiments/npu/analysis/channel_tolerance_sensitivity.py`](../../experiments/npu/analysis/channel_tolerance_sensitivity.py)
(저장된 run artifact에서 재계산). 기록: [TASK49](TASK49.md).

## 대상과 두 판정 형태

채널 일치 요건이 판정에 선행한 측정은 4건, 게이트가 적용된 셀은 **20칸**이다.

| TASK | run | 채널 A 정의 | 등록한 판정 형태 | 셀 수 |
|---|---|---|---|---|
| [TASK34](TASK34.md) | `20260823-170201-compile-config` | decode 전용 | `차 ≤ 0.02` (고정 밴드) | 3 |
| [TASK35](TASK35.md) | `20260823-183505-final-confirm` | A′ = decode + prefill | `차 ≤ 0.02` (고정 밴드) | 6 |
| [TASK36](TASK36.md) | `20260824-160028-n6-reconfirm` | A′ = decode + prefill | `차 ≤ τ(N) = max(0.02, r_BASE/B_BASE)` | 2 |
| [TASK40](TASK40.md) | `20260824-222453-batch-saturation` | A′ = decode + prefill | `차 ≤ τ(N) = max(0.02, r_BASE/B_BASE)` | 9 |

τ 형태는 [TASK36](TASK36.md)에서 도입됐으므로 [TASK34](TASK34.md)·[TASK35](TASK35.md)
시점에는 존재하지 않았다. 그래서 아래 민감도는 두 형태를 **모두** 계산한다.

- `fixed` — `차 ≤ 기본값`. [TASK34](TASK34.md)·[TASK35](TASK35.md)가 실제 등록한 형태.
- `tau` — `차 ≤ max(기본값, r_BASE/B_BASE)`. [TASK36](TASK36.md)·[TASK40](TASK40.md)가
  등록한 형태. 두 번째 항은 자료에서 그대로 산출하며 이 분석에서 변경하지 않는다.

## 재현 대조

재계산값을 각 TASK 문서의 기록값과 대조했다. **20칸의 A비·B비 40개가 소수 넷째
자리까지 전부 일치**하고, 문서가 잔차비를 인쇄한 4건(τ(6)=0.0377, τ(6)=0.0356,
τ(8)=0.0400, τ(10)=0.0464)도 일치한다. 대조 실패 시 script는 종료한다.

    --output results/npu/stage2/channel_tolerance_sensitivity.json
