# 정상성 재분석 — 같은 길이 기준 (방법 선등록)

작성: 2026-09-30, Advisor 지시문 06 작업 A. **분석만, 판정 없음(보고).** 이 절(§1–§4)은 계산 전에 commit한다. 결과는 §5에 계산 후 덧붙인다.

## 1. 문제

[TASK82](TASK82.md)는 평가 구간 전·후반(각 60 s)의 h TVD(0.25–0.48)를 **replicate 간 120 s 전체 구간** h TVD(0.10–0.24)와 비교해 "60 s 해상도에서는 정상 상태가 아니다"라고 적었다. 두 값은 창 길이가 달라 표본 잡음이 다르다 — 60 s 창은 step 수가 절반이라 같은 분포에서도 TVD가 커진다. 같은 길이의 기준으로 다시 본다.

## 2. 데이터

- run `results/npu/stage3/20260930-main/`([TASK82](TASK82.md)), 13 cell(N 6·8·10·12 × BASE·BATCHONLY·TUNED + DP N8). cell마다 **그 cell의 유효 lifecycle 전부**(N8 TUNED·DP는 r0–r9 10개, 나머지 r0–r4 5개). 모든 lifecycle이 유효했다.
- 창: lifecycle의 평가 구간 `[w0, w0 + 120)`를 `[w0, w0 + 60)`(전반)과 `[w0 + 60, w0 + 120)`(후반)으로 나눈다. **정의는 [TASK82](TASK82.md) `main_analyze.halves`와 같다**: 요청은 보낸 시각으로 창에 속하고, h는 server 창(평가 구간 첫 요청의 ALLOC ~ 마지막 요청의 ALLOC)의 `[BUCKET]` step을 후반 첫 요청의 ALLOC 위치에서 둘로 나눈다. 재사용률은 창에 속한 turn ≥ 1 요청 중 `cached > 0` 비율(`cached`는 client 값, `null`이면 server 조회 줄).

## 3. 비교 분포와 요약 통계

cell 하나에서 replicate 집합 R(|R| = 5 또는 10), 창 위치 p ∈ {전, 후}.

**h(n)**

- 관심 통계(run 안): `W_r = TVD(h_전(r), h_후(r))`, r ∈ R.
- 같은 길이 기준(run 사이, 같은 위치): `B = { TVD(h_p(r), h_p(r')) : r < r', p ∈ {전, 후} }` — 5 replicate면 20개, 10 replicate면 90개.
- cell 요약: `q_h = mean_r F_B(W_r)`, `F_B(x)` = B 안에서 x보다 작은 값의 비율 + 같은 값의 절반(중간 순위 백분위). run 안 두 창이 run 사이 같은 위치 창과 같은 정도로 다르면 `q_h ≈ 0.5`.
- 함께 보고: `median(W)`, `median(B)`.

**재사용률**

- 관심 통계: `Δ_r = reuse_후(r) − reuse_전(r)`.
- 같은 길이 기준: `D = { reuse_p(r') − reuse_p(r) : r ≠ r', p ∈ {전, 후} }` (순서쌍, 부호 대칭).
- 방향 요약: `q_Δ = mean_r F_D(Δ_r)`. 후반 하락이 run 사이 변동보다 한쪽으로 치우치면 `q_Δ < 0.5`.
- 크기 요약: `q_|Δ| = mean_r F_{|D|}(|Δ_r|)`.

## 4. "비정상"이라고 부를 조건 (계산 전 고정)

- **h 비정상**: 13 cell의 `q_h` 중앙값 > 0.75 **그리고** `q_h > 0.5`인 cell 수 k에 대한 단측 부호 검정 `P(K ≥ k | Bin(13, 0.5)) < 0.05`(k ≥ 10). 둘 중 하나만 성립하면 `약한 증거`, 둘 다 불성립이면 **같은 길이 기준에서는 비정상이라 부르지 않는다**.
- **재사용 후반 하락**: `q_Δ` 중앙값 < 0.25 **그리고** `q_Δ < 0.5`인 cell 수에 대한 같은 단측 부호 검정 < 0.05. 같은 방식으로 `약한 증거`를 둔다.
- 모든 백분위는 경계값을 포함한 중간 순위로 계산한다. 판정이 아니라 보고 분류이며, 결과를 본 뒤 이 조건을 바꾸지 않는다.
- 결과가 "같은 길이 기준에서도 비정상"이면 원인(warm-up 규칙의 초기 renewal 위상 대 gap 꼬리)을 가를 기존 데이터 분석을 **제안만** 한다(지시문 06 §3.4).
