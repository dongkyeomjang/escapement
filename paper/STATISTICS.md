### 1.1 비용 비 (정상 상태 실험)

| 항목 | NPU (TASK82·87·95·102) | GPU (GTASK11·20) |

**[파생] k = 5에서 CI = [짝 비 최솟값, 최댓값].** 5개 중 3개 이상을 x(1)로 뽑을 확률 = Σ_{j≥3} C(5,j)·0.2^j·0.8^(5−j) = 0.0579 > 0.025다. 그래서 2.5 % 분위는 x(1), 97.5 % 분위는 x(5)다.
- 확인: NPU k = 5 비 cell 23개 전부, GPU GTASK20 비 cell 8개(4 cell × 2 bound) 전부 `ci == [min(per_rep), max(per_rep)]`.
- 따라서 GTASK11 문서의 CI 경계(예: N24 POOL [0.8122, 0.9704])는 그 cell replicate별 짝 비의 최솟값·최댓값이다.

## 2. "통계적으로 구분 가능한 쌍"과 "순위 일치"의 판정 규칙

### 2.1 규칙

| 항목 | NPU (§5.3) | GPU (§5.3) |
|---|---|---|
| 쌍 | N마다 구성 쌍 전부(`itertools.combinations`). 3구성 → 3쌍, TASK82 N8(DP 포함 4구성) → 6쌍 | (BASE, POOL), (BASE, POOL+GRID), (POOL, POOL+GRID) |
| 통계량 | 짝 비 `X/Y`(replicate별)의 중앙값 m과 1.1의 CI [l, u] | 같음, bound별 |
| **해소된 쌍** | `not (l ≤ 1 ≤ u)` | 같음 |
| [파생] k = 5에서 해소 ⇔ | 5개 짝 비가 모두 1보다 작거나 모두 1보다 크다(1.1의 CI = [min, max]). 짝 비가 독립이고 중앙이 1이면 이 사건의 확률은 2 × 0.5^5 = 0.0625 | 같음 |
| 관측 싼 쪽 | 해소된 쌍에서 `u < 1`이면 X, 아니면 Y | `m > 1`이면 Y, 아니면 X(해소된 쌍에서는 NPU 규칙과 같은 결과) |
| 예측 싼 쪽 | 주 예측기의 예측 turn당 device time(plan 5개 합산) 순위 `rank`가 작은 쪽 | GTASK11: 해석 `device_per_turn_s`가 작은 쪽. GTASK20: 주 예측기 ctx `price_per_turn_s`가 작은 쪽 |
| N별 판정 | 해소된 쌍이 0 → `UNRESOLVED`. 해소된 모든 쌍에서 예측 싼 쪽 = 관측 싼 쪽 → `PASS`, 하나라도 다르면 `FAIL` | 같음 |
| 전체 판정 | 해소된 N이 하나라도 있고 모두 PASS → `PASS` | N별·bound별 보고 |
| 미해소 쌍 | 판정에 들어가지 않는다(일치·불일치 어느 쪽으로도 세지 않음) | 같음 |
| 코드 | `main_analyze.py:main`(§5.3), 각 `*_analyze.py:main` | `main_judge.py:main`, `blind_judge.py:main` |

## 3. 같은 실행 안의 요청 간 상관

| 지표 | 처리 | 요청 간 상관의 영향 |
|---|---|---|
| 비용 비 m과 CI | lifecycle 하나의 요청·step 전부를 turn당 A′ 값 하나로 줄인 뒤, 그 값의 짝 비를 **replicate 단위로** 재표집 | 요청은 재표집 단위가 아니므로 run 안 상관은 CI 계산에 들어가지 않는다. 대신 독립 단위가 k = 5뿐이다(1.1의 [파생]: CI = 관측 범위) |
| 재사용률(cell) | replicate 5개의 요청을 합친 비율(요청 단위). CI 없음 | 선등록 §5.1 허용차 근거 "cell당 요청 수(≈ 500–800)에서 표본 오차(±0.03)"는 요청 독립(이항) 가정의 크기다. replicate 간 산포는 판정에 쓰지 않았다 |
| h(n) | step 수 합산 분포의 TVD. CI 없음 | 같은 성질 |
| 정상성 | run 안 전·후반 60 s 차이를 **run 사이 같은 위치 60 s 차이**와 비교(요청 독립 가정을 쓰지 않는 기준) | NPU TASK83, GPU GTASK16 |

### 3.1 [사후] 재사용률: replicate 기반 표준오차 대 이항 표준오차

정의: `SE_binom = sqrt(p(1 − p)/n)`(p = cell 합산 비율, n = `turn ≥ 1` 요청 합), `SE_rep = sd(replicate 비율 5개)/sqrt(5)`, 설계 효과 `DE = (SE_rep / SE_binom)^2`. DE > 1이면 run 안 요청이 독립 표본보다 정보가 적다는 뜻이다(run 간 변동 > 이항 변동).
