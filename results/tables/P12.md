## 비고

- NPU 운영 context = run 로그 재계산(TASK82·87·95, 깨끗한 decode step, 측정·시뮬레이션 없음). GPU 운영 context = GTASK18 plan 기준값(GTASK11 plan, decode step 가중).
- 원래 비용: NPU = 통제 측정 descriptor 비용(`sim`), GPU = 가격(짧은 context 통제 측정, (3)).
- GPU 열의 lo / hi는 GTASK20 두 bound. NPU 재사용 MAE·비 Σ는 TASK102 §5.1·§5.2 정의.
